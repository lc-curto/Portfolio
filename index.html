01 / CONTEXTO

Do conhecimento da operação ao software.

A experiência na distribuição de cosméticos ajuda-me a reconhecer problemas que vale a pena resolver com software.

No Cosmetics Hub, estou a transformar esse contexto num produto incremental. O objetivo é organizar empresas, clientes, catálogo, inventário, encomendas e valores a receber. O portefólio distingue a base já construída das funcionalidades ainda planeadas.

02 / PROJETO PRINCIPAL

Cosmetics Hub

MVP de gestão comercial para empresas de cosméticos.

EM DESENVOLVIMENTO

O problema e o objetivo

Reunir num só sistema os dados e fluxos comerciais que sustentam uma operação de distribuição: empresas, clientes, catálogo, inventário, encomendas e contas a receber.

A implementação é feita por etapas. O âmbito do produto não significa que todos estes módulos estejam implementados.

Estado verificável

API · base funcionalEndpoint de saúde, testes automatizados e PostgreSQL para desenvolvimento local.
